# قدّيش بتعرفني؟ V7 — الجولة العاشرة

**جولة إحياء العوالم والخطوط والتفاعل البصري**، مع إضافة الحقوق:

> جميع الحقوق محفوظة — 𝑴𝒖𝒔𝒂 𝑨𝒍-𝑨𝒉𝒎𝒂𝒅

## التغييرات

- 4 عوالم حية ومتفاعلة بصريًا، عبر طبقات آمنة فوق الصور الأصلية في `public/world-ambience.js`.
- خطوط Tajawal للنصوص وChanga للعناوين (من Google Fonts مع fallback محلي).
- مؤثرات ضغط وأصوات إضافية للأزرار وبطاقات الاختيار، وحفظ خيار إيقاف الحركة.
- صور الشخصيات الخمس وملفات الموسيقى الخمسة **لم تتغير**.

## تشغيل محلي

```bash
npm test
npm start
```

**Node.js >=22.13.0**. يمكن إيقاف الموسيقى والمؤثرات والصوت وحركة العوالم من نافذة الإعدادات. قد يمنع المتصفح تشغيل الصوت دون تفاعل، وقد لا تتوفر خطوط Google دون إنترنت.

**القبول النهائي: NO-GO للنشر العام**. هذه نسخة تطوير مع فحوص محلية، وتبقى التجارب الفعلية على أجهزة Android وiPhone، وروابط HTTPS، والنسخ الاحتياطية والأداء تحت الحمل مطلوبة. التقارير: `V7-ROUND-10-REPORT.md` و`V7-TEN-GATES.md`.
