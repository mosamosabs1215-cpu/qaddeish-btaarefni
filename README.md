# 🤪 قدّيش بتعرفني؟

موقع تفاعلي عربي لصناعة تحدّيات الأصدقاء: 15 سؤالًا لكل تحدٍّ، رابط مستقل، تصحيح موثوق على الخادم، نتائج كوميدية، لوحة متصدرين، وإحصائيات خاصة بصاحب التحدّي.

## المزايا المنجزة

- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر، شخصيات كرتونية مرسومة بـCSS، ثيمات متعددة، حركات وتفاعلات، وخلفيات تتغير خلال اللعب.
- **210 سؤالًا** جاهزًا ضمن **21 فئة**، بحث وتصفية، أسئلة خاصة، إزالة وإعادة ترتيب.
- إنشاء 15 سؤالًا مع إجابة محددة لكل سؤال، ومعاينة قبل النشر.
- رابط عام فريد لكل تحدٍّ (`/q/ID`) ورابط إدارة سري منفصل (`/dashboard/ID#key=SECRET`).
- تصحيح الأسئلة في الخادم وإخفاء الإجابات الصحيحة عن واجهات المشاركين.
- محاولات حقيقية تُحفظ في قاعدة SQLite، استئناف اللعب على المتصفح نفسه، ومنع إرسال الإجابة مرتين.
- ستة مستويات تقييم و24 تعليقًا نهائيًا متنوعة، 20 تعليقًا أثناء الإجابة، ومشاركة النتائج، وتنزيل بطاقة PNG.
- ترتيب مستقل وإحصائيات لكل تحدٍّ، مع الإيقاف المؤقت والحذف.
- 7 اختبارات API تلقائية تغطي العزل والصلاحيات والتصحيح والنتائج.
- تشغيل بلا اعتماديات خارجية أو مفاتيح API.

## بدء التشغيل (على الكمبيوتر أو الخادم)

**المتطلب:** Node.js 22.13 أو أحدث (يتضمن SQLite المدمج).

```bash
cd knowme-site
npm start
```

افتح:

`http://localhost:3000`

للتطوير مع إعادة تشغيل الخادم تلقائيًا:

```bash
npm run dev
```

الاختبارات:

```bash
npm test
```

قد يظهر تنبيه من Node 22 يفيد بأن وحدة `node:sqlite` تجريبية، وهو تحذير من المنصة وليس فشلًا للتشغيل. اختُبر المشروع باستخدام Node 22.16.

## التشغيل عبر Docker

```bash
docker compose up --build -d
```

سيعمل الموقع على `http://localhost:3000` وستُحفظ بياناته في مجلد `data/` على جهاز الاستضافة بواسطة volume، بدل فقدها مع إعادة إنشاء الحاوية.

## نشر الموقع على الإنترنت

يلزم خادم يدعم Node.js ويقدم **قرص تخزين دائم (persistent volume)** لملف SQLite. يصلح VPS، أو استضافة حاويات تدعم أقراصًا دائمة. اربط نطاق الموقع، واضبط HTTPS من خلال reverse proxy مناسب.

1. ارفع محتويات المشروع إلى الخادم.
2. شغّل `npm start` (أو Docker)، واضبط `PORT` حسب الاستضافة.
3. استخدم متغير `DATA_DIR` لمجلد دائم، مثل `/app/data`.
4. فعّل HTTPS ثم اضبط `NODE_ENV=production` لكي تصبح cookies آمنة عند النقل.
5. افتح عنوان الموقع الحقيقي، وأنشئ تحديًا. روابط المشاركة تُنشأ تلقائيًا باستعمال اسم نطاق الموقع المنشور.
6. خذ نسخة احتياطية دورية من ملف قاعدة البيانات باستخدام آلية SQLite backup سليمة (مثل `VACUUM INTO` أو واجهة النسخ الاحتياطي)، أو أوقف الكتابة مؤقتًا أثناء نسخ الملفات المتعلقة بـWAL.

**مهم:** عنوان `localhost` لا يعمل عند أصدقائك خارج جهازك؛ روابط المشاركة العالمية تبدأ بالعمل بعد نشر الموقع على نطاق عام.

## ملاحظات الخصوصية والأمان

- رابط التحدي العام لا يحتوي رمز الإدارة ولا الإجابات الصحيحة.
- رمز إدارة المالك يُخزّن مجزّأً SHA-256 في قاعدة البيانات؛ نسخة الرمز الأصلية تُقدَّم عند الإنشاء وتُحفظ في متصفح المالك.
- لا ترسل رابط الإدارة الخاص إلى أحد؛ حفظه مهم لاستعادة التحكم من جهاز آخر.
- لا حاجة لتسجيل حساب، لذا لا يمكن إثبات أن شخصًا مجهول الهوية *لم* ينشئ متصفحًا جديدًا لمحاولة ثانية. يوجد منع محاولة رسمية ثانية **لكل متصفح** فقط باستخدام cookie.
- تحديد الطلبات مبسط ويعمل داخل عملية خادم واحدة؛ للحماية الأكبر أمام جمهور واسع أضف حماية عند البوابة مثل CDN/WAF ومراقبة إساءة الاستخدام.
- يُفضّل أن تختار أسئلة لا تكشف بيانات شخصية حساسة، لأن أصحاب الروابط يمكنهم معرفة السؤال وخياراته، والإجابة صحيحة/خاطئة بعد اختيارهم.
- الموقع يعمل بلا Firebase؛ قاعدة البيانات فعلية ومحلية للخادم. هذا يجعل التشغيل والتجربة أبسط، لكن الاستضافة يجب أن تحافظ على الملف الدائم.

## حدود الإصدار الحالي

- لا يوجد تسجيل حساب Google أو نظام بريد لاسترجاع مفتاح إدارة ضائع؛ خيار الاستعادة هو الاحتفاظ برابط الإدارة السري.
- لا توجد ميزة QR Code حاليًا.
- صياغة الأسئلة في شاشة الصديق تتحول تلقائيًا لبعض الأسئلة الشائعة، والبقية تظهر بصيغة سؤال مقتبس من صاحب التحدي.
- أفضل خيار للنمو الكبير إلى آلاف الاتصالات المتزامنة أو خوادم متعددة هو نقل التخزين إلى PostgreSQL ونقل الحد من الطلبات إلى بنية مشتركة.

## الملفات

- `server.mjs`: خادم HTTP، قاعدة البيانات، REST API، والتحقق من الإجابات والصلاحيات.
- `public/index.html`: بوابة التطبيق.
- `public/styles.css`: الهوية البصرية والحركات ودعم الشاشات.
- `public/app.js`: واجهات إنشاء التحدي واللعب والإحصائيات والمشاركة.
- `public/questions.json`: بنك الأسئلة العربية.
- `tests/api.test.mjs`: اختبارات API.
- `generate_bank.py`: المصدر الذي يُعيد توليد بنك الأسئلة إذا رغبت في تعديله.

**الواجهة:** عربية شامية خفيفة بطابع كوميدي. البرنامج قابل لتعديل الاسم والألوان والأسئلة والشخصيات.
